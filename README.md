# 🍦 Sorveteria Sweetly 

Projeto de desenvolvimento web de uma página para uma sorveteria fictícia, criado como atividade acadêmica.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3

## 🎨 Sobre o projeto

O Sweetly é um site desenvolvido para apresentar uma sorveteria de forma visualmente atrativa, com um design pensado para proporcionar uma boa experiência ao usuário.
